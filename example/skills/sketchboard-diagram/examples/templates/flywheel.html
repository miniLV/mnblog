LLM Wiki Agent Memory 飞轮

每天自动整理会话，每周只晋升稳定经验；下一次任务通过 memory loader 把这些经验带回来，形成持续自我迭代的本地知识库。

飞轮不是定时备份 真正的价值在于：Daily 负责记录，Weekly 负责筛选，Apply 负责让经验回到未来任务。

周度复盘
