# sketchboard-diagram (vendored for mnblog)

Sparse copy of [miniLV/sketchboard-diagram](https://github.com/miniLV/sketchboard-diagram) for blog covers and in-post diagrams.

## Install full skill elsewhere

```bash
npx skills add https://github.com/miniLV/sketchboard-diagram
# or clone the repo and point agents at its SKILL.md
```

## In this package

- `SKILL.md` — agent workflow
- `examples/templates/` — architecture + flywheel starters (+ cover template for mnblog)
- `scripts/` — HTML→PNG via headless Chrome (`CHROME_PATH` optional)
- `docs/patterns/` — credited pattern PNGs for demos when you have not rendered yet

Do not vendor `.scratch` or large research trees.
